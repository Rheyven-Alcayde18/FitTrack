FITTRACK - .NET 10 WINDOWS FORMS

Requirements:
- Windows
- .NET 10 SDK
- Visual Studio Code (with C# support recommended)

Run in VS Code:
1. Extract this ZIP file.
2. Open the FitTrack_SharpDevelop51 folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: dotnet restore
5. Run: dotnet run

Design:
- Keeps the original FitTrack aqua and turquoise color palette.
- Phone-sized layout with compact navigation.
- Rounded cards, clear typography, and consistent spacing.
- Dashboard statistics and weekly activity chart.

Features:
- Dashboard
- My Workouts
- Workout History and sorting
- Fitness Goals
- Progress
- Settings
