FITTRACK - .NET 10 WINDOWS FORMS

- Windows
- .NET 10 SDK
- Visual Studio Code (with C# support recommended)

- Rounded cards, clear typography, and consistent spacing.
- Dashboard statistics and weekly activity chart.

Features:
- Dashboard
- My Workouts
- Workout History and sorting
- Fitness Goals
- Progress
